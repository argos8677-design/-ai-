# 프로젝트: BIKEBANK AI MARKETING PLATFORM

## 1. 프로젝트 역할 및 목표

당신은 글로벌 SaaS 플랫폼을 개발하는 시니어 풀스택 개발자이자 UX/UI 전문 기획자입니다.

대한민국 전기 이륜차 렌트 전문기업인 바이크뱅크(주)의 AI 마케팅 자동화 플랫폼을 개발해 주세요.

이 서비스는 바이크뱅크의 전기 이륜차 렌트 상품을 기반으로 AI가 자동으로 마케팅 콘텐츠를 제작해 주는 웹 플랫폼입니다.

사용자가 렌트 상품과 홍보 대상, 마케팅 채널을 선택하면 AI가 해당 상품의 특징을 분석하여 블로그, 유튜브 쇼츠, 인스타그램, 페이스북, 카카오톡 등에 활용할 수 있는 마케팅 소재를 자동 생성하는 것이 핵심 기능입니다.

### 서비스 기본 정보

- 서비스명: BIKEBANK AI MARKETING
- 운영기업: 바이크뱅크(주)
- 사업 분야: 배터리 스왑 방식 전기 이륜차 렌트
- 서비스 유형: AI 기반 마케팅 콘텐츠 자동 생성 SaaS
- 기본 언어: 한국어
- 주요 사용자: 배달 라이더, 개인사업자, 배달대행업체, 이륜차 대리점, 제휴 파트너

### 핵심 슬로건

"렌트 상품만 선택하세요. 마케팅은 AI가 완성합니다."

# 2. 전체 웹사이트 구성

웹사이트는 다음 3개의 페이지를 중심으로 구성합니다.

1. 메인페이지
2. AI 마케팅 소재 생성 페이지
3. 마케팅 활용 방법 페이지

### 공통 네비게이션

상단에 고정형 헤더를 배치합니다.

- BIKEBANK AI 로고
- 서비스 소개
- AI 소재 생성
- 활용 방법
- AI 소재 만들기 버튼

각 메뉴를 클릭하면 해당 페이지로 이동해야 합니다.

AI 소재 만들기 버튼은 항상 강조된 색상으로 표시합니다.

# 3. PAGE 01. 메인페이지

## 3-1. 메인 비주얼

첫 화면에서 서비스의 목적과 핵심 기능이 명확하게 전달되어야 합니다.

메인 카피:

"렌트 상품만 선택하세요.
마케팅 콘텐츠는 AI가 만들어 드립니다."

서브 카피:

"바이크뱅크의 전기 이륜차 렌트 상품을 기반으로 블로그부터 쇼츠, SNS까지. AI가 고객별 맞춤형 마케팅 콘텐츠를 자동으로 제작합니다."

버튼:
- AI 마케팅 소재 만들기
- 서비스 이용 방법 보기

메인 이미지에는 전기 이륜차, 배터리 교환 스테이션, 배달 라이더, 디지털 콘텐츠 제작 화면을 활용합니다.

실제 모빌리티 기업의 공식 서비스처럼 전문적이고 신뢰감 있게 표현합니다.

## 3-2. 서비스 소개

제목:

"마케팅이 어려운 렌트 영업, 이제 AI가 해결합니다."

① 상품 기반 AI 콘텐츠 생성
- 바이크뱅크의 실제 렌트 상품 정보 반영
- 상품별 특징과 장점 자동 분석
- 고객 유형에 따른 맞춤형 홍보 문구 생성

② 다양한 채널 콘텐츠 제작
- 네이버 블로그
- 유튜브 쇼츠
- 인스타그램
- 페이스북
- 카카오톡

③ 간편한 콘텐츠 활용
- 원클릭 콘텐츠 생성
- 생성 결과 복사
- 콘텐츠 다운로드
- 수정 및 재생성

## 3-3. AI 콘텐츠 제작 프로세스

제목:

"단 3단계로 완성하는 AI 마케팅"

STEP 01. 렌트 상품 선택

STEP 02. 타깃 고객 및 마케팅 채널 선택

STEP 03. AI 마케팅 콘텐츠 자동 생성

각 단계를 아이콘과 카드형 디자인으로 시각화합니다.

탭을 클릭하면 해당 채널의 샘플 콘텐츠가 표시되어야 합니다.

실제 생성 결과처럼 보이는 자연스러운 한국어 예시를 사용합니다.

# 4. PAGE 02. AI 마케팅 소재 생성 페이지

이 페이지가 본 서비스의 가장 중요한 핵심 기능입니다.

사용자가 복잡한 프롬프트를 직접 입력하지 않아도 몇 가지 항목만 선택하면 마케팅 콘텐츠가 생성되는 직관적인 UI를 구현합니다.

## 4-1. 화면 레이아웃

PC 화면에서는 다음과 같이 구성합니다.

- 왼쪽: 입력 및 선택 영역
- 오른쪽: AI 콘텐츠 생성 결과 영역

모바일에서는 위아래로 배치합니다.

페이지 제목:

"AI 마케팅 콘텐츠 생성"

설명:

"바이크뱅크의 렌트 상품과 홍보 목적을 선택하면 AI가 채널별 최적화 콘텐츠를 제작합니다."

## 4-2. STEP 01. 렌트 상품 선택

상품을 카드형 UI로 표시합니다.

상품 유형:
- 단기 렌트 (1년 미만)
- 장기 렌트 (1년 이상)

각 상품 카드에는 다음 정보를 표시합니다.

- 상품명
- 차량 이미지
- 차량 모델
- 렌트 기간
- 월 렌트료
- 보증금
- 배터리 스왑 관련 정보
- 상품의 주요 장점

중요한 개발 조건:

실제 상품 정보가 제공되지 않았으므로 임의로 렌트료, 보증금, 차량 사양, 혜택을 확정하지 않습니다.

초기에는 테스트용 샘플 상품을 등록하되 샘플 데이터라는 사실을 명확하게 표시합니다.

향후 관리자가 실제 상품 정보를 등록하고 수정할 수 있도록 데이터베이스 구조를 설계합니다.

## 4-3. STEP 02. 타깃 고객 선택

다음 항목을 복수 선택할 수 있도록 구현합니다.

- 배달 라이더
- 신규 배달업 종사자
- 개인사업자
- 배달대행업체
- 법인 및 사업자
- 이륜차 대리점
- 제휴 파트너
- 일반 소비자
- 기타

고객 유형에 따라 AI가 사용하는 문체와 강조 메시지가 달라져야 합니다.

예를 들어 배달 라이더에게는 배달 업무 편의성과 운행 효율성을 강조하고, 대리점에는 렌트 상품의 사업적 활용성과 제휴 가능성을 강조합니다.

## 4-4. STEP 03. 마케팅 채널 선택

복수 선택이 가능하도록 카드형 UI를 구현합니다.

### 네이버 블로그
- SEO 최적화 제목
- 블로그 본문
- 소제목
- 핵심 키워드
- 해시태그
- 고객 상담 유도 문구

- 시작 3초 후킹 문구
- 장면별 스토리보드
- 자막
- 내레이션
- 영상 제목
- 영상 설명
- 해시태그

### 인스타그램
- 피드 게시글
- 릴스 대본
- 카드뉴스 문구
- 이미지용 홍보 카피
- 해시태그

### 페이스북
- 상품 홍보 게시글
- 광고 카피
- 고객 유입 문구

### 카카오톡
- 고객 발송용 메시지
- 상품 소개 문구
- 상담 유도 메시지

## 4-5. STEP 04. 마케팅 목적 선택

다음 항목을 선택할 수 있도록 합니다.

- 신규 고객 유치
- 렌트 상품 홍보
- 장기 렌트 계약 유도
- 단기 렌트 홍보
- 신규 배달 라이더 모집
- 기존 고객 재계약 유도
- 대리점 및 제휴점 모집
- 브랜드 인지도 향상

## 4-6. STEP 05. 추가 요청사항

자유롭게 입력할 수 있는 텍스트 입력창을 배치합니다.

안내 문구:

"강조하고 싶은 상품 특징이나 원하는 홍보 방향을 입력하세요."

입력 예시:

- 배터리 교환 방식의 장점을 강조해 주세요.
- 초기 비용 부담에 관심 있는 고객을 대상으로 작성해 주세요.
- 신규 배달 라이더에게 적합한 홍보 문구를 작성해 주세요.
- 대리점에서 고객에게 설명하기 쉬운 콘텐츠로 작성해 주세요.

## 4-7. AI 콘텐츠 생성 버튼

버튼명:

생성 중에는 로딩 애니메이션과 진행 상태를 보여줍니다.

# 5. PAGE 03. 마케팅 활용 방법

## 5-1. 페이지 목적

AI로 생성한 콘텐츠를 실제 마케팅 활동에 활용하는 방법을 알려주는 가이드 페이지입니다.

제목:

"AI가 만든 콘텐츠, 이렇게 활용하세요."

서브 카피:

"콘텐츠 생성부터 고객 유입까지. 바이크뱅크의 렌트 상품을 더 효과적으로 홍보하는 방법을 안내합니다."

## 5-2. 채널별 활용 가이드

### ① 네이버 블로그

활용 절차:

1. AI 블로그 콘텐츠 생성
2. 제목과 본문 복사
3. 실제 차량 및 배터리 교환 이미지 추가
4. 네이버 블로그 게시
5. 고객 문의 유도

추천 콘텐츠:
- 전기 이륜차 렌트의 장점
- 배터리 스왑 방식 소개
- 배달 라이더를 위한 렌트 가이드
- 단기 렌트와 장기 렌트 비교
- 전기 이륜차 이용 방법

### ② 유튜브 쇼츠

활용 절차:

1. AI 쇼츠 대본 생성
2. 장면별 구성 확인
3. 실제 차량 및 배터리 스왑 영상 촬영
4. 자막과 내레이션 적용
5. 유튜브 쇼츠 게시

추천 콘텐츠:
- 배터리 교환 방법
- 배달 라이더의 하루
- 전기 이륜차 렌트 이용 방법
- 렌트 상품 주요 장점
- 고객이 궁금해하는 렌트 정보

### ③ 인스타그램

활용 절차:

1. AI 게시글 생성
2. 홍보 이미지 준비
3. 해시태그 적용
4. 인스타그램 게시
5. DM 및 상담 유도

### ④ 페이스북 및 카카오톡

활용 절차:

- 페이스북 페이지 상품 홍보
- 지역별 배달 라이더 커뮤니티 활용
- 카카오톡 고객 대상 상품 안내
- 기존 고객 재계약 홍보

## 5-3. 실제 마케팅 활용 사례

사례 1. 신규 배달 라이더 확보

- 상품: 전기 이륜차 장기 렌트
- 대상: 신규 배달 라이더
- 채널: 네이버 블로그, 유튜브 쇼츠
- 목적: 신규 렌트 고객 유치

사례 2. 단기 렌트 홍보

- 상품: 단기 렌트
- 대상: 단기 배달업 종사자
- 채널: 인스타그램, 카카오톡
- 목적: 단기 렌트 문의 확대

사례 3. 대리점 제휴 확대

- 상품: 바이크뱅크 렌트 상품

# 6. 디자인 가이드

- 모던하고 미니멀한 UI
- 넓은 여백
- 직관적인 카드형 디자인
- 부드러운 라운드 처리
- 은은한 그림자
- 명확한 타이포그래피
- 불필요한 애니메이션 최소화
- 버튼과 선택 영역의 시각적 구분 강화

- 배터리 교환 스테이션
- 배달 라이더
- 전기 이륜차 렌트 관련 실제 업무 장면
- AI 콘텐츠 제작 화면

일반적인 AI 로봇 이미지만 사용하는 것을 지양하고 전기 이륜차 모빌리티 사업과 직접적으로 연관된 이미지를 사용합니다.

# 7. 기술 및 개발 요구사항

### 프론트엔드

- React
- TypeScript
- Tailwind CSS
- 컴포넌트 기반 설계
- 반응형 웹
- 직관적인 라우팅

### 백엔드 및 데이터베이스

Supabase를 활용할 수 있도록 구조를 설계합니다.

필요한 데이터 테이블:

1. products: 렌트 상품 정보
2. product_images: 상품 이미지
3. content_history: 콘텐츠 생성 이력
4. content_results: 채널별 생성 결과
5. users: 사용자 정보
6. prompt_templates: 채널별 AI 프롬프트

### AI API 연동

실제 AI API를 연결할 수 있는 구조로 구현합니다.

필수 조건:

- API 키는 서버 측에서만 관리
- 프론트엔드에 API 키 노출 금지
- 서버 측 API 호출
- 상품 데이터와 AI 프롬프트 분리
- 채널별 프롬프트 개별 관리
- 결과 데이터 JSON 구조화
- 오류 발생 시 사용자 안내

AI API가 아직 연결되지 않은 상태에서는 데모 콘텐츠를 활용하여 전체 사용자 흐름을 테스트할 수 있도록 합니다.

데모 결과와 실제 AI 생성 결과는 명확하게 구분합니다.

# 8. AI 콘텐츠 생성 정확성 및 광고 준수사항

AI는 바이크뱅크가 등록한 실제 상품 데이터를 기준으로 콘텐츠를 생성해야 합니다.

다음 사항을 반드시 준수합니다.

1. 실제 등록되지 않은 렌트 상품을 임의로 생성하지 않습니다.
2. 실제와 다른 렌트료 및 보증금을 작성하지 않습니다.
3. 확정되지 않은 할인 및 혜택을 사실처럼 표현하지 않습니다.
4. 배터리 교환소 위치와 운영시간을 임의로 생성하지 않습니다.
5. 확인되지 않은 차량 성능 및 주행거리를 작성하지 않습니다.
6. 경쟁사를 근거 없이 비방하지 않습니다.
7. 허위·과장 광고 표현을 방지합니다.
8. 확인되지 않은 정보는 '회사 확인 필요'로 표시합니다.
